# JAAK Pulse

JAAK Pulse se despliega **en la infraestructura del propio cliente**: binarios nativos gestionados por systemd, distribuidos como artefactos firmados (minisign/Ed25519) que la máquina descarga tras validar la licencia. Los datos del negocio nunca salen de la infraestructura del cliente.

## Documentación

- [Instalación de la cámara Pulse](/docs/pulse/instalacion-camara) — guía paso a paso para instalar una cámara desde que llega: enchufar, conectarse al Access Point `JAAK_PULSE` y configurar la red (WiFi, cable, proxy o circuito cerrado). Incluye solución de problemas.
- [Guía de despliegue y operación](/docs/pulse/guia-cliente) — guía enterprise (grado procurement/security) del despliegue con Terraform en OCI: arquitectura, prerequisitos, modos de actualización, seguridad y privacidad, operación y soporte.
- [Instalación con script (get-pulse)](/docs/pulse/instalacion) — instalación nativa en una VM Linux propia (Ubuntu/Debian) con tu propia Oracle 26ai, sin Terraform/OCI: un solo comando `curl | sudo bash`.
